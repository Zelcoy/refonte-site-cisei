# Benchmark : sites comparables

Date : 24/11/2026. 11 sites étudiés (pages d'accueil et parfois code source). Les codes couleur et polices proviennent du code ; les remarques d'ambiance sont à vérifier à l'écran.

## Enseignements transversaux

1. **La base de données doit être visible dès l'accueil.**
2. **Le modèle gratuit puis membre fonctionne s'il est transparent** : aperçu, explication de la fiche complète, adhésion à ce moment-là.
3. **Accompagner la recherche** : conseils, variantes d'orthographe, guides, aide humaine.
4. **Des récits avec des noms propres**, filtrables, alimentés par des contributions et encadrés par une charte éthique.
5. **Multilingue rédigé, pas traduit automatiquement**, avec `hreflang` et sélecteur visible.
6. **Accessibilité visible** : contraste, taille du texte, langage simplifié.

## Trois directions artistiques

### A. « Registro » : l'archive savante

- **Intention** : centre d'études de référence, inspiré des registres d'embarquement et fiches cartonnées. Confiance, précision, durée.
- **Palette** : ivoire `#F4EFE4`, encre bleu-noir `#1F2A3A`, rouge registre `#A3302A`, ardoise `#6B7280`, filets `#D9CFBF`.
- **Typographies** : sérif de lecture (Source Serif 4, Newsreader) ; police tabulaire pour les données (IBM Plex Mono ou Plex Sans).
- **Images** : documents d'archive recadrés serré, légendés comme des pièces de collection ; noir et blanc non colorisé.
- **Accueil** : recherche plein écran sur fond papier avec compteur « 3 000 000+ nomi », chiffres clés, publications et newsletter, trois récits, annuaire, partenaires.

### B. « Partenze » : le voyage et la mer

- **Intention** : approche émotionnelle pour les descendants. Gênes, le port, la traversée ; la recherche comme première étape d'une histoire familiale.
- **Palette** : bleu « Lanterna » `#0E3B5C`, écume `#DCE6EC`, ocre ligure `#C98A2E`, terre de Sienne `#8A4B2D`, blanc cassé `#FAF8F4`.
- **Typographies** : sérif éditorial (Fraunces, DM Serif Display) ; sans-serif humaniste (Inter, Source Sans 3).
- **Images** : grandes photos d'archive en duotone bleu/ivoire ; portraits pour les récits ; cartes des routes migratoires.
- **Accueil** : grand visuel avec recherche par-dessus, carte « Dove sono andati », récits en carrousel, adhésion en trois paliers, newsletter, publications.

### C. « Rete » : le réseau contemporain

- **Intention** : plateforme vivante d'une diaspora connectée, pour des descendants plus jeunes et les institutions.
- **Palette** : blanc `#FFFFFF`, gris `#F2F2F0`, noir chaud `#1A1A1A`, vert désaturé `#2F7D5B`, corail `#E2553F`, bleu donnée `#3B6EA8`.
- **Typographies** : grotesque (Space Grotesk, Archivo) et version condensée pour les données ; Inter pour le texte.
- **Images** : archives en formats carrés ou ronds mises en regard de photos actuelles (« hier / aujourd'hui ») ; icônes au trait ; visualisations de données.
- **Accueil** : recherche compacte dans l'en-tête, tableau de bord du fonds, « Racconta la tua storia », carte de l'annuaire, espace membre, publications.

## Recommandation

Prototyper **A** et **B** en priorité : A pour la crédibilité scientifique, B pour l'adhésion des descendants. Les modules de C (carte des communautés, visualisations, dépôt participatif) s'intègrent dans l'une ou l'autre.
